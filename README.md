# 🛍️ NovaCart — Animated E-Commerce Website

NovaCart is a modern, responsive, and animated **E-Commerce website** built using **HTML, CSS, and JavaScript**. It provides a smooth shopping experience with product filtering, search, cart management, animations, and a responsive interface.

## ✨ Features

* 🎨 Modern and responsive UI
* ✨ Smooth animations and hover effects
* 🛍️ 200+ products
* 💻 50 Tech products
* 🏠 50 Home products
* 👕 50 Fashion products
* 💄 50 Beauty products
* 🔎 Product search functionality
* 🏷️ Category-based product filtering
* 🛒 Add to cart functionality
* ➕ Increase/decrease product quantity
* ❌ Remove products from cart
* 💰 Automatic cart total calculation
* 💾 Cart data stored using LocalStorage
* ❤️ Wishlist/heart interaction
* ⏳ Limited-time sale countdown
* 📧 Newsletter subscription
* 🔔 Toast notifications
* 📱 Fully responsive design
* 🚚 About section with store features

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, responsive design and animations
* **JavaScript** — Dynamic functionality and interactions
* **LocalStorage** — Cart persistence
* **Google Fonts** — Inter typography

## 🛒 Shopping Features

NovaCart includes a fully interactive shopping cart.

Users can:

1. Browse products
2. Filter products by category
3. Search for products
4. Add products to the cart
5. Increase or decrease quantity
6. Remove products
7. View the total price
8. Proceed through the demo checkout

Cart information is saved in the browser using **LocalStorage**, so the cart remains available after refreshing the page.
